Cross-Architecture Vulnerability Detection Through Embedding Alignment

Project Summary

Detecting vulnerabilities in compiled software remains a difficlt challenge, particularly when source code is unavailable. Machine learning models trained on x86-64 binaries may perform poorly on ARM64 due to differences in instruction sets and code representations. This project proposes to investigate whether a vulnerability classifier trained on x86-64 can be transferred to ARM64 without retraining the classifier or requiring labelled ARM64 vulnerability data.

Background and Rationale

Recent studies have explored cross-architecture binary representations using graph-based learning and instruction embeddings. Approaches such as Gemini, XBA, and CAIE demonstrate the potential of learning representations across processor architectures. However, aligning embeddings does not necessarily preserve the information required to distinguish vulnerable functions from safe ones.

Research Gap

Existing research has largely focused on binary similarity and jointly trained cross-architecture models. Less attention has been paid to transferring an existing vulnerability classifier through a separately trained embedding adapter while keeping the classifier unchanged.

Aim and Objectives

The overall aim of this project is to evaluate whether embedding alignment enables vulnerability detection across processor architectures without labelled target-domain training data.

The specific objectives are:

1. To develop and compare methods for aligning x86-64 and ARM64 function embeddings.
2. To evaluate how embedding alignment affects the classification accuracy of a frozen vulnerability detector.

Research Questions

1. Can an embedding adapter trained on unlabelled function pairs transfer an x86-64 vulnerability classifier to ARM64?
2. Does improved embedding similarity necessarily lead to better vulnerability detection?

Methodology

The project will adopt a quantitative experimental approach. A dataset will be constructed by compiling C/C++ functions for x86-64 and ARM64 using several optimisation levels. Corresponding functions will be extracted and converted into vector embeddings.

Four alignment methods will be compared: constant vector translation, linear mapping, orthogonal Procrustes alignment, and a multilayer perceptron.

An x86-64 vulnerability classifier will be trained separately and its parameters frozen. Each adapter will then transform ARM64 embeddings into the classifier's input space.

Performance will be measured using recall, precision, F1 score, PR-AUC, and false-positive rate. Data will be separated by source project to reduce information leakage. Particular attention will be paid to cases where embeddings align geometrically but produce different classification decisions.

Expected Outcomes

The project is expected to produce a comparative evaluation of alignment methods, an experimental dataset, and an open-source implementation. The findings may clarify whether geometric similarity is sufficient for transferring vulnerability classifiers.

Timeline

The proposed research will take twelve months. Months 1–3 will cover literature review and dataset preparation. Months 4–7 will focus on model development and alignment experiments. Months 8–10 will involve evaluation and error analysis, followed by documentation and publication preparation in Months 11–12.

Budget and Justification

The estimated budget is €3,500: €2,000 for computational resources, €500 for data storage and infrastructure, and €1,000 for conference participation and research dissemination.

Broader Impact

The proposed approach could reduce the need for architecture-specific vulnerability datasets and simplify security analysis of embedded systems and firmware. Releasing the implementation may also support reproducible research in binary analysis.
