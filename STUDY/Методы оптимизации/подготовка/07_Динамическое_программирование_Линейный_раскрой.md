# 7. Динамическое программирование для задачи о линейном раскрое

**Задача одномерного раскроя:** есть заготовки длины $L$ и заказы на детали длины $\ell_i$ в количестве $d_i$, $i=1,\ldots,m$. Нужно минимизировать число израсходованных заготовок (или отходы при фиксированном объёме заказа). Длины и потребности здесь целочисленны.

**Принцип Беллмана:** оптимальное продолжение решения из текущего состояния не зависит от способа попадания в это состояние.

## 1. ДП для заполнения одной заготовки

Пусть $p_i$ — полезность одной детали типа $i$; временно допустим неограниченное число деталей каждого типа. Максимальная полезность заполнения остатка длины $s$:

$$
V(0)=0,\quad V(s)=\max\left\{0,\ \max_{i:\ell_i\le s}[p_i+V(s-\ell_i)]\right\},\quad s=1,\ldots,L.
$$

Переход перебирает тип **первой** отрезанной детали. В оптимальном раскрое первым может быть любой тип; оставшаяся часть оптимальна для длины $s-\ell_i$, иначе её можно улучшить — противоречие. Отсюда корректность рекурсии по индукции по $s$. Сложность $O(mL)$ по времени и $O(L)$ по памяти. Если заказ ограничивает количество деталей, к состоянию добавляют остатки потребностей.

## 2. ДП для минимального числа заготовок

**Шаблон раскроя** $a=(a_1,\ldots,a_m)\in\mathbb Z_+^m$ допустим, если $\sum_i\ell_i a_i\le L$ и $a\ne0$. Обозначим множество шаблонов $P$. Состояние $r=(r_1,\ldots,r_m)$ — оставшаяся потребность. Тогда

$$
\boxed{F(0)=0,\quad F(r)=1+\min_{\substack{a\in P\\0\le a\le r}}F(r-a),\quad r\ne0.}
$$

Обоснование: в любом оптимальном решении существует первая заготовка с некоторым шаблоном $a$; остальные $F(r-a)$ заготовок должны быть оптимальны. И наоборот, приписывание шаблона $a$ к оптимальному решению подзадачи даёт допустимый раскрой. По индукции рекурсия возвращает точный минимум.

**Пример:** $L=10$, $\ell_1=6$, $\ell_2=4$, $d=(2,2)$. Шаблон $(1,1)$ заполняет длину $10$, поэтому $F(2,2)=1+F(1,1)=2$. Меньше двух нельзя: суммарная длина заказов $20$.

**Ограничение:** векторное ДП имеет до $\prod_i(d_i+1)$ состояний; для больших заказов обычно используют линейную релаксацию, генерацию столбцов и ветвление.

**Основа:** Романовский, *Дискретный анализ* (2008), разделы о динамическом программировании и дискретной оптимизации; Wolsey, *Integer Programming* (2008).
