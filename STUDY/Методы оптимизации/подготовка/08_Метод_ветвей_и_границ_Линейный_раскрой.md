# 8. Метод ветвей и границ для задачи о линейном раскрое

**Модель раскроя.** Пусть $P$ — набор всех допустимых шаблонов $a_p=(a_{1p},\ldots,a_{mp})\in\mathbb Z_+^m$, $\sum_i\ell_i a_{ip}\le L$. Переменная $x_p$ — число заготовок, раскроенных по шаблону $p$. Решаем целочисленную задачу

$$
\boxed{\min\sum_{p\in P}x_p\quad\text{при}\quad
\sum_{p\in P}a_{ip}x_p\ge d_i\ (i=1,\ldots,m),\quad x_p\in\mathbb Z_+.}
$$

**Идея ветвей и границ (Branch and Bound):** разбить множество целочисленных решений на подзадачи, у каждой вычислять **нижнюю оценку** оптимума и отбрасывать ветви, не способные улучшить найденное допустимое решение.

**Алгоритм:**

1. В корне снять целочисленность: $x_p\ge0$. Решить задачу ЛП, её оптимум $z_{LP}$ — нижняя граница: $z_{LP}\le z^*_{IP}$. Дополнительно можно взять $\lceil z_{LP}\rceil$, поскольку целевая функция целочисленна.
2. Получить любой целочисленный раскрой с затратами $U$ — **верхнюю границу** (текущий рекорд).
3. Если решение ЛП целочисленно, обновить $U$ и закрыть узел. Если ЛП недопустима — закрыть узел. Если нижняя граница $L_{node}\ge U$ — закрыть узел по оценке.
4. Иначе выбрать дробную переменную $x_p^*=q+\theta$, $0<\theta<1$, и образовать **две ветви**:

$$
x_p\le\lfloor x_p^*\rfloor=q
\quad\text{или}\quad
x_p\ge\lceil x_p^*\rceil=q+1.
$$

Ни одно целочисленное решение родительской задачи не теряется. Повторять для оставшихся узлов до их закрытия. При полном переборе с корректными оценками получаем **глобальный оптимум**.

**Пример:** $L=10$, детали длины $4$, заказ $d=3$. Можно разместить по две детали в заготовке. Модель: $\min x$ при $2x\ge3$, $x\in\mathbb Z_+$. ЛП даёт $x=1.5$, $L=1.5$; целочисленный раскрой из двух заготовок даёт $U=2$. Ветвление: $x\le1$ недопустимо, $x\ge2$ даёт $x=2$. Итак, $z^*=2$.

**Обоснование отсечения:** если для всех решений узла $f(x)\ge L_{node}\ge U$, то ни одно решение узла не лучше текущего рекорда. При большом числе шаблонов столбцы можно генерировать по мере необходимости — получается **branch-and-price**.

**Сложность:** в худшем случае экспоненциальная; качество нижних оценок и стратегия ветвления определяют практическую скорость.

**Основа:** Wolsey, *Integer Programming* (2008); Мину, *Математическое программирование* (1990).
