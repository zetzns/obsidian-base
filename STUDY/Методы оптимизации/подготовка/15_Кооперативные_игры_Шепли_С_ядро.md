# 15. Кооперативные игры. Вектор Шепли. С-ядро

**Кооперативная игра с передаваемой полезностью** задаётся парой $(N,v)$: $N=\{1,\ldots,n\}$ — множество игроков, $v:2^N\to\mathbb R$, $v(\varnothing)=0$ — **характеристическая функция**, равная выигрышу, доступному коалиции $S$ самостоятельно. **Делёж** — вектор $x\in\mathbb R^n$ с $\sum_{i\in N}x_i=v(N)$.

## Вектор Шепли

Средний предельный вклад игрока при равновероятном порядке вступления игроков в коалицию:

$$
\boxed{\phi_i(v)=\sum_{S\subseteq N\setminus\{i\}}
\frac{|S|!(n-|S|-1)!}{n!}\bigl[v(S\cup\{i\})-v(S)\bigr].}
$$

**Вывод коэффициента.** Для заданного $S$ игроки из $S$ должны прийти до $i$ (в $|S|!$ порядках), затем $i$, а остальные — после него (в $(n-|S|-1)!$ порядках). Всего порядков $n!$, следовательно, множитель — вероятность данного набора предшественников.

**Аксиомы Шепли:** эффективность $\sum_i\phi_i=v(N)$, симметрия равноправных игроков, правило игрока с постоянным предельным вкладом (*dummy*), аддитивность $\phi(v+w)=\phi(v)+\phi(w)$. Эффективность сразу следует из телескопической суммы вкладов в каждой перестановке: $v(N)-v(\varnothing)=v(N)$. Эти аксиомы однозначно задают вектор Шепли. **Почему единственно:** любую игру можно разложить по играм единогласия $u_T(S)=\mathbf1\{T\subseteq S\}$ как $v=\sum_{T\ne\varnothing}a_Tu_T$ (коэффициенты находятся обращением Мёбиуса). Для $u_T$ аксиомы игрока с постоянным вкладом, симметрии и эффективности однозначно дают $\phi_i=1/|T|$ при $i\in T$ и $0$ иначе; аддитивность затем однозначно определяет $\phi(v)$.

## С-ядро (core)

**С-ядро** — множество дележей, которые никакая коалиция не может улучшить для своих участников за счёт собственного ресурса:

$$
\boxed{C(N,v)=\left\{x\in\mathbb R^n:\sum_{i\in N}x_i=v(N),\ 
\sum_{i\in S}x_i\ge v(S)\ \forall S\subseteq N\right\}.}
$$

С-ядро может быть пусто. Например, у трёх игроков $v(N)=1$, $v(\{i,j\})=1$ для любой пары, $v(\{i\})=0$. Условия для трёх пар дают $2\sum_ix_i\ge3$, но эффективность требует $\sum_ix_i=1$: противоречие.

**Отличие Шепли от С-ядра:** Шепли — **единственный вектор** справедливого распределения согласно аксиомам; С-ядро — **множество** устойчивых дележей. Даже при непустом С-ядре вектор Шепли может в него не входить. В примере из пособия Наумовой $v(\{1,2\})=v(\{1,3\})=v(N)=1$, остальные значения $0$: $\phi=(2/3,1/6,1/6)$, но $C=\{(1,0,0)\}$.

**Теорема:** для выпуклой кооперативной игры, где

$$
v(S)+v(T)\le v(S\cup T)+v(S\cap T),
$$

вектор Шепли принадлежит С-ядру. **Доказательство:** зафиксируем порядок вступления $\pi$ и его вектор предельных вкладов $g^\pi$. Для любой коалиции $S$ вклад каждого её игрока при вступлении после всех предыдущих по $\pi$ не меньше его вклада после лишь предыдущих игроков из $S$ (выпуклость игры означает возрастание предельных вкладов). Суммируя по игрокам $S$, получаем $\sum_{i\in S}g_i^\pi\ge v(S)$ — меньшие вклады телескопически складываются в $v(S)$. Кроме того, $\sum_{i\in N}g_i^\pi=v(N)$; значит, $g^\pi\in C(N,v)$. С-ядро выпукло, а $\phi$ — среднее векторов $g^\pi$, откуда $\phi\in C(N,v)$. $\square$
