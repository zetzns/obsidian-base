
Введём обозначения:

$$\begin{gathered}
Ax=b\\
A_{б}x_{б}+A_{c}x_{c}=b\\
A_{б}x_{б}=b-A_{c}x_{c} \\
x_{б}=A^{-1}_{б}b- A_{б}^{-1}A_{c}x_{c}\\
\\
\text{Отсюда} \\
x_{б}^{0}=A_{б}^{-1}b=\beta_{б},\quad\alpha=-A_{б}^{-1}A_{c}.
\end{gathered}$$
где $x_б^0$ - начальный вектор базисных переменных.
Тогда
$$x_{б}=\alpha x_{c}+x_{б}^{0}.$$
Соответственно $x_i$ и целевая функция выглядят так:
$$\begin{gathered}
x_{i}=\sum\limits_{j=m+1}^{n}\alpha_{ij}x_{j}+x_{i}^{0},\ \ i=1..m,\\
f(x)=f_{0}+\sum\limits_{j=m+1}^{n}\Delta_{j}x_{j}.
\end{gathered}$$
Из этих равенств получается таблица

|         | $$x_{m+1}$$      | $$...$$ | $$x_{k}$$       | $$...$$ | $$x_{n}$$    | $$x_б^0=\beta$$        |
| ------- | ---------------- | ------- | --------------- | ------- | ------------ | ---------------------- |
| $$x_1$$ |                  |         |                 |         |              |                        |
| $$...$$ |                  |         |                 |         |              |                        |
| $$x_l$$ |                  |         | $$\alpha_{lk}$$ |         |              | $$x_l^0$$              |
| $$...$$ |                  |         |                 |         |              |                        |
| $$x_m$$ |                  |         |                 |         |              |                        |
| $$f$$   | $$\Delta_{m+1}$$ | $$...$$ | $$\Delta_k$$    | $$...$$ | $$\Delta_n$$ | $$f_0=c_б^0A_б^{-1}b$$ |
