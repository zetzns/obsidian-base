# Смена признакового пространства 

> [!info] 
> Если сама задача модели одна, но входные данные отличаются
> 
> Пример: NLP текстов разных языков

# Смена пространства распределения признаков

> [!info] 
> Если входные данные и задача одни, а вот распределение - разное 
> 
> Пример: ревью приложения -> ревью фильма

# Смена пространства меток

> [!info] 
> Меняется суть задачи
> 
> Пример: классификация лиц по половому признаку -> по расовому

# Supervised/ Unsupervised

> [!info] 
> Деление по принципу наличия разметки данных для дообучения
