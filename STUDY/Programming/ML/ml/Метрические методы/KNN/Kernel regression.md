	
> [!idea] 
> Алгоритм KNN `можно обобщить на задачу регрессию`. Так, например, можем просто взять для ядра обычное среднее: $$a(u)=\frac{1}{k}\sum_{i=1}^ky_u^{(i)},$$ либо взвешенный вариант, $$a(u)=\frac{{\sum_{i=1}^kK\left({\frac{\rho(u,x_u^{(i)})}{h}}\right)y_u^{(i)}}}{\sum_{i=1}^kK\left(\frac{{\rho(u,x_u^{(i)})}}{h}\right)}$$

> [!info] 
> Формула взвешенного варианта носит имя `Надарая-Ватсона`. Она — один из непараметрических методов восстановления регрессии, объединённых названием _ядерная регрессия_.

> [!important] 
> Для обобщения задачи на регрессию нужно `заменить индикатор` на **гладкую функцию** метрики (расстояния). Например, квадрат евклидова расстояния $(y-y_u^{(i)})^2$. 
> Получается, что **максимизация близости эквивалентна максимизации расстояния, и получим следующую формулу:** $$a(u)=argmin_{y\in\mathbb{R}}\sum_{i=1}^kK\left(\frac{\rho(u,x_u^{(i)})}{h}\right)(y-y_u^{(i)})^2$$

> [!finally] 
> Тогда формула Надарая-Ватсона становится точным решением этой оптимизационной задачи.
